## 3. 検討・判断したこと

- `content.tex` が図版を参照している各ディレクトリに `assets/` を作成し、該当する `fig-ch04-*.png` を配置した。
- TeX からの参照は、中央の `assets/generated_figures/ch04/...` ではなく、同一ディレクトリ配下の `assets/fig-ch04-*.png` に変更した。
- 元の `tex/assets/generated_figures/ch04` は統合 TeX 側の既存参照で使われる可能性があるため削除しなかった。

## 4. 実施した作業

- CH04 構造ツリー内で図版参照を持つ `content.tex` を抽出した。
- 参照される `fig-ch04-01.png` から `fig-ch04-15.png` を、参照元 `content.tex` と同じディレクトリの `assets/` へコピーした。
- 各 `content.tex` の `\IfFileExists` と `\includegraphics` のパスを `assets/fig-ch04-*.png` に更新した。
- 参照先 asset の存在確認と `git diff --check` を実行した。
