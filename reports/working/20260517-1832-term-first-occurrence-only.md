# 作業完了レポート

保存先: `reports/working/20260517-1832-term-first-occurrence-only.md`

## 1. 受けた指示

- TeX において、一回目に登場した用語は太字かつ英語併記にする。
- 二回目以降に登場した同じ用語は、太字にせず英語も入れない。

## 2. 要件整理

| 要件ID | 指示・要件 | 重要度 | 対応状況 |
|---|---|---:|---|
| R1 | 用語の初出だけを太字かつ英語併記にする | 高 | 対応 |
| R2 | 同じ用語の二回目以降は通常テキストにする | 高 | 対応 |
| R3 | 生成スクリプト経由で再生成可能にする | 高 | 対応 |
| R4 | 全体 TeX/PDF の生成可否を確認する | 高 | 対応 |

## 3. 検討・判断したこと

- 既存生成物では `\term{日本語}{English}` が出現するたびに太字かつ英語併記になるため、生成後の章本文を文書順に走査する後処理を追加した。
- 表示時だけの LaTeX マクロ制御ではなく、生成される章別 TeX から二回目以降の `\term` 自体を通常テキストへ戻す方針にした。
- 初出判定は全体 PDF の文書順で行い、章ごとにはリセットしない解釈とした。

## 4. 実施した作業

- `tex/build_integrated_document.py` に `keep_first_term_occurrences` を追加した。
- 生成済みの章本文リストに対して、初出の `\term` / `\keyterm` だけを残し、二回目以降を日本語の通常テキストへ置換するようにした。
- `python3 tex/build_integrated_document.py` で統合 TeX、章別 TeX、master TeX を再生成した。
- LuaLaTeX を 2 回実行し、PDF 生成と相互参照の収束を確認した。
